# AIMEREK — THE YOUTIFUL STORY

Интерактивті, адаптивті сайт-фильм Аймерек апайға арналған. Жоба React, TypeScript, Vite, Tailwind CSS және Motion for React негізінде жасалған.

## Іске қосу

```bash
npm ci
npm run dev
```

Production жинағын тексеру:

```bash
npm run build
npm run preview
```

## Контент

Негізгі расталған деректер `src/data/aimerek.ts` файлында сақталады. Белгісіз деректер `null` немесе бос массив күйінде қалады. Фотосурет, жетістік және музыка қосу тәртібі [CONTENT_GUIDE.md](./CONTENT_GUIDE.md) файлында берілген.

Маршруттар:

- `/` — кіріспе, басты экран, хикая, галерея, алғыс және финал;
- `/achievements` — расталған жетістіктер;
- `/her-world` — музыка мен волейбол туралы бөлімдер.

## Қолжетімділік

Сайт пернетақтамен басқаруды, семантикалық белгілерді, сурет alt-мәтіндерін және `prefers-reduced-motion` баптауын қолдайды. Музыка тек пайдаланушы әрекетінен кейін қосылады және файлдар жоқ кезде интерфейс жұмысын жалғастырады.
